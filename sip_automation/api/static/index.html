Bulk upload format:
  • One row per employee.
  • Fill in only the columns that apply to that employee (e.g. just bp_fy26_rev + bp_fy26_rev_direction) and leave the rest blank.
  • If you enter an amount, its matching _direction column (+ or -) is required, or that row will be rejected.
  • BP FY26 Rev / BP FY26 GP only affect the "Target Exceptions" metric shown in results - they do not change the payout.
  • YTD FY26 Rev / YTD FY26 GP are the fields that actually affect payout - they feed "Approved Exceptions in Regional Currency", which flows into the SIP calculation.
  • Uploading adds/updates only the employees in your file - other exceptions (including manually-added ones) are kept. If an employee is in both, the file replaces that employee's exception(s).
